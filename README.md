# THE RESIDENCE 南風原 — Portfolio

架空の新築マンションPRサイトです。面接用ポートフォリオとして制作することを想定しています。

## ファイル
- index.html：サイト本体
- style.css：デザイン・レスポンシブ対応
- script.js：メニュー、間取りモーダル、問い合わせフォームなどの動作

## 起動方法
index.html をブラウザで開くだけで動作します。

## 面接で説明できるポイント
- HTMLでセマンティックなページ構成を作成
- CSS Grid / Flexboxでレイアウト
- PC・スマートフォン向けレスポンシブ対応
- JavaScriptでハンバーガーメニュー、間取り詳細モーダル、フォーム送信デモを実装
- Google Fontsを利用したタイポグラフィ設計
- 架空のマンションを題材に、企画・デザイン・実装を一貫して制作
